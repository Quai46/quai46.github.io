# quai46.github.io
Quai 46 — Genève. Vêtements minimalistes.

Site statique (HTML/CSS/JS, sans framework ni backend) publié sur GitHub Pages : https://quai46.github.io

## Structure
- `index.html`, `collection.html`, `a-propos.html`, `contact.html` — pages principales (FR)
- `mentions-legales.html`, `confidentialite.html`, `cgv.html` — pages légales (FR)
- `en/` — version anglaise de toutes les pages (le lien FR/EN mène à la page équivalente)
- `404.html`, `sitemap.xml`, `robots.txt`
- `css/style.css` — styles (mobile first) · `js/main.js` — menu, animations, formulaires
- `assets/` — image de partage (`og-image.png`), polices auto-hébergées (`fonts/`), photos produits (`products/`)
- `images/` — illustrations (Jet d'Eau, Léman)

## À personnaliser
Voir `INFORME.md` : liste complète des `TODO`, configuration de Formspree (`FORMSPREE_ID`),
photos à fournir. Toute modification d'une page FR doit être reportée dans sa version `en/`.
